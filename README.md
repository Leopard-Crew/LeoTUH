# LeoTUH

Leopard Translation Unit Helper (LeoTUH) prepares temporary translation-unit bundles for faster local Leopard/PPC development builds.

LeoTUH is not 
- a build system.
- a compiler wrapper.
- an IDE.

LeoTUH only prepares temporary translation-unit aggregation files for existing Leopard/PPC make, xcodebuild, Xcode, and gcc workflows.

If the generated directory is deleted, the project returns to its normal build behavior.
